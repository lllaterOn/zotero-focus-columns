# Focus Columns 1.0.0 人工验收清单

> 历史结论：该候选版本因缺少 Zotero 10 必需的 `applications.zotero.update_url` 而无法安装，未通过验收。此文档仅保留原始验收范围；后续修复见 `MANUAL_ACCEPTANCE_1.0.1.md`。

本清单用于验证 GitHub Draft Release 中的确切 XPI。自动测试不能替代真实 Zotero 10 界面和跨电脑同步验收。

开始前请备份两台电脑的 Zotero 数据目录，并记录候选 XPI 的 SHA-256。

## 纯净安装准备

1. 确认旧插件已经卸载，旧的 `Personal Zotero Addons` 条目及其删除状态已经通过 Zotero 自带同步传播到两台电脑。
2. 关闭 Zotero。
3. 如需完全重新开始，在两台电脑分别删除旧的本机文件：
   - `<Zotero data directory>/focus-columns-publications.json`
   - `<Zotero data directory>/focus-columns-backups/`
4. 不复制旧首选项、旧同步笔记或旧缓存到 1.0.0。

## 第一台电脑

1. 从私人 Draft Release 下载 `zotero-focus-columns-1.0.0.xpi`，核对 `SHA256SUMS`。
2. 在 Zotero `10.0.*` 中从文件安装插件，重启 Zotero，并打开 Focus Columns 设置页。
3. 确认插件名称、图标和版本 `1.0.0` 正确，设置页面没有横向滚动、文字重叠或异常缩放。
4. 分别切换四个条目列表列和两个条目面板信息行，确认六个开关互不影响。
5. 填写本机 EasyScholar 密钥并应用设置；不得在截图、日志、笔记或验收记录中复制密钥。
6. 验证期刊标签更新和删除、`#` 标签、互斥状态以及 `remark:` 简记；确认条目 `Extra` 中其他内容保持不变。
7. 对主值相同的条目切换四个自定义列排序，确认后续顺序仍由 Zotero 的次级和后备排序决定。

## 创建新的同步数据

1. 确认跨电脑同步默认关闭，期刊标签通道默认选中，设置通道默认未选中。
2. 开启同步并确认创建计划。
3. 确认个人文献库中只出现一个 `Personal Zotero Addons` 软件条目及一个 `Focus Columns` 子笔记。
4. 确认状态区区分本机和同步笔记的期刊数量，时间精确到分钟，正常状态不重复网络同步说明。
5. 检查子笔记：不得包含 EasyScholar 密钥、电脑名称、用户名、硬件信息或设备标识。
6. 修改一期刊标签，等待本机笔记更新，然后点击 Zotero 自带同步按钮并等待完成。

## 第二台电脑

1. 先让 Zotero 下载第一台电脑创建的共享条目和子笔记。
2. 从同一个私人 Draft Release 下载 XPI，核对 SHA-256 后安装。
3. 开启 Focus Columns 同步，确认连接已有条目和笔记，而不是创建第二套对象。
4. 采用 Zotero 中的期刊标签数据，确认期刊标签恢复；本机 EasyScholar 密钥仍为空或只保留这台电脑单独填写的值。
5. 保持设置同步关闭，在第二台电脑修改一个功能开关；完成 Zotero 同步后，确认第一台电脑没有跟随变化。
6. 开启设置同步，制造一次两端同时修改，确认插件要求选择完整的本机版本或 Zotero 版本，不静默合并。

## 异常与卸载

- 制造可恢复的同步错误，确认摘要和异常详情显示为错误状态，时间信息仍保持弱化。
- 将 Focus Columns 子笔记移入回收站，确认插件暂停且不自动创建替代笔记；恢复后可以重新连接。
- 关闭同步，确认共享条目和子笔记保留。
- 卸载插件，确认共享条目和子笔记仍然保留。

## 发布结论

只有当上述检查全部通过，并且安装文件 SHA-256 与 Draft Release 中 `SHA256SUMS` 一致时，才将同一个 Draft Release 发布为正式 Release。验收失败时不得重新构建并覆盖同一版本资产。
