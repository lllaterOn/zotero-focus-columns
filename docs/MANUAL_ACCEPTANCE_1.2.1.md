# Focus Columns 1.2.1 人工验收清单

本版本修复视图组工具栏文字被裁切的问题，尚未正式发布。基础代码检查、自动化测试和包校验由维护阶段完成；不自行启动 Zotero，实际界面由用户测试。使用本轮 Draft 的同一份 XPI，未报告的结果保持未勾选。

- [ ] 下载 `zotero-focus-columns-1.2.1.xpi`，核对其 SHA-256 与 Draft 的 `SHA256SUMS` 一致；不覆盖或改动 1.2.0 候选。
- [ ] 从 1.2.0 在运行中升级，工具栏显示列布局图标和下拉箭头，没有被截断的“视图”文字；重启后仍正常，按钮不重复。
- [ ] 在常用显示缩放、深浅主题及开合右侧栏时，图标可见、没有被压扁，与相邻按钮协调；点击后菜单正常打开。
- [ ] 悬停提示包含当前视图的完整名称；切换、重命名、接收同步定义后，提示和菜单中的当前项正确更新。未保存视图或删除当前组时，提示回到“视图组”。
- [ ] 展开右侧栏时，各个可伸缩列随列表变窄；关闭后重新分配宽度。只开合侧栏不会更新视图组；临时调整列宽后切走再切回仍采用原保存值，主动更新才保存调整。
- [ ] 使用本轮同一份 1.2.1 XPI 执行 [1.2.0 清单](MANUAL_ACCEPTANCE_1.2.0.md) 中保存、切换、排序、选择、缺失插件列及两台电脑同步的功能项目；旧清单的版本号与发布步骤不适用于本轮。
- [ ] 用户确认后才正式发布当前 Draft 的确切资产；不重新构建或替换已验收 XPI。正式发布前，`updates.json` 继续只包含已发布版本。
