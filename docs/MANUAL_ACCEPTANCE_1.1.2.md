# Focus Columns 1.1.2 人工验收清单

本轮针对 `1.1.1` 截图中 `#标签` 弹窗仍过宽的问题。用户反馈功能行为正常，但宽度未通过验收。`1.1.2` 尚未完成真实 Zotero 10 视觉验收；源码尺寸约束和 HTML 布局检查不能证明原生弹窗已达到目标，也不能单独确认问题的完整原因。

## 确切候选

- [ ] 从 `v1.1.2` Draft 下载 `zotero-focus-columns-1.1.2.xpi` 和 `SHA256SUMS`，核对下载文件 SHA-256、校验和文件及 GitHub 资产摘要一致。
- [ ] 两台电脑均安装这个确切 XPI，重启 Zotero `10.0.*` 并确认版本 `1.1.2`，不使用本地重建包代替。
- [ ] 确认 `updates.json` 未包含 `1.1.0`、`1.1.1` 或 `1.1.2` 候选；保留旧候选和旧清单，不替换资产。

## 宽度复验

- [ ] 在与原截图相同的列宽和显示缩放下打开短标签列表，确认可见边框宽度约为 190 CSS 像素，侧边没有多余大片留白。测量不包含外侧阴影，截图物理像素需按显示缩放换算。
- [ ] 使用中文和较长标签，确认弹窗可适度扩宽，但可见边框宽度不超过 280 CSS 像素；字号、行高、搜索和清除操作保持可用。
- [ ] 搜索长文本、筛选短标签、清空搜索，并检查无匹配、空列表及大量候选滚动，确认没有再次撑宽、横向溢出或控件被截断。
- [ ] 调宽和调窄 `#标签` 列，连续打开不同条目的菜单，确认宽度由候选内容合理决定，不随状态列或 `#标签` 列无界扩张。
- [ ] 在两台电脑各自的显示缩放、窗口及屏幕边缘重复检查；如使用不同缩放的显示器，也检查跨屏后的宽度、首次居中和边缘避让。

## 功能回归

使用同一个 `1.1.2` Draft XPI 执行 [1.1.1 清单](MANUAL_ACCEPTANCE_1.1.1.md) 中“焦点与关闭”“多选与撤销”“列表重绘与位置失效”“功能回归与两台电脑”的检查；该旧清单中的候选版本和发布步骤不适用于本轮。

- [ ] 搜索不会在打开时自动获取焦点；关闭和外部点击不抢焦点，连续点击无需额外一次点击。
- [ ] `#标签` 和状态列保留多选，选择、清除及撤销范围正确，非 `#` 标签保留。
- [ ] 后台行重绘不会意外隐藏菜单；滚动列表或移动窗口时合理关闭；简记共用行为无回归。
- [ ] 两台电脑完成上述回归，并记录候选校验和、Zotero 版本、显示缩放及宽度结果。截图和记录不得包含用户名、本机路径、密钥或凭证。

## 发布门槛

- [ ] 用户确认实际宽度及回归结果通过后，才发布现有 `1.1.2` Draft，不重建或替换已验收 XPI。
- [ ] `1.1.0`、`1.1.1` 保持未发布。若本轮失败，保留候选，在新版本中修正并重新验收。
- [ ] 正式发布后确认 `updates.json` 新增 `1.1.2`，公开下载地址、SHA-256 和兼容范围与已验收资产一致；从正式版 `1.0.1` 检查自动更新，旧正式版仍可下载。
