# Focus Columns 1.1.3 人工验收清单

## 验收与发布记录

用户已明确接受 `1.1.3` 并授权正式发布。[v1.1.3](https://github.com/lllaterOn/zotero-focus-columns/releases/tag/v1.1.3) 于 2026-09-12 正式发布，使用原 Draft 的同一个 XPI，未重建或替换资产。其 SHA-256 为：

```text
3e33be73716b9fded096e84a30b2e9e89f325d322f7428d904949774524b70ad
```

发布后的更新清单已包含正式版 `1.0.1` 和 `1.1.3`；`1.1.0`、`1.1.1`、`1.1.2` 仍为未发布候选。

以下保留发布前的验收步骤，供追溯与复用，不表示版本仍在等待发布。用户给出了总体接受结论，未逐项报告全部测试或两台电脑的结果，因此原有复选框保持未勾选，不据此宣称每一项均已验证。

本轮修正运行中升级仍可能加载旧 CSS 的问题，保留 `1.1.2` 的弹窗宽度限制、字号和行高，并清零搜索框原生外边距，消除其造成的 8 CSS 像素横向溢出。隔离的原生 Zotero `10.0.2` 无界面测试已复现：替换 CSS 并清除启动缓存后，相同 URL 仍得到旧宽度；仅为 URL 添加版本参数即可加载新规则并得到 190 CSS 像素的短标签弹窗。本测试未检查用户 profile，不能替代实际升级与交互验收。

## 确切候选与运行中升级

- [ ] 从 `v1.1.3` Draft 下载 `zotero-focus-columns-1.1.3.xpi` 和 `SHA256SUMS`，确认下载文件 SHA-256、校验和文件及 GitHub 资产摘要一致；两台电脑均使用这个确切 XPI。
- [ ] 在运行着旧版插件的 Zotero 中先打开一次 `#标签` 弹窗，使旧样式被加载。记录版本、显示缩放及当前宽度。
- [ ] 保持 Zotero 运行，从文件安装 `1.1.3` Draft XPI。先不要重启、卸载旧版或手动清缓存；确认插件版本已更新，并重新打开相同条目的弹窗。
- [ ] 确认新样式立即生效：短标签可见边框宽度约为 190 CSS 像素，不再保留旧的大块留白。边框测量不包括外侧阴影，截图物理像素需按显示缩放换算。
- [ ] 完整退出并重新启动 Zotero，确认仍为 `1.1.3`，相同弹窗宽度与重启前一致，设置和条目数据保留。

## 宽度与功能回归

使用上述同一个 `1.1.3` XPI 执行 [1.1.2 清单](MANUAL_ACCEPTANCE_1.1.2.md) 的“宽度复验”和“功能回归”，包括其中引用的旧版功能检查。旧清单的安装版本及发布步骤不适用于本轮。

- [ ] 检查短标签、长标签、中文、搜索输入与清空、无匹配、空列表及大量候选滚动；长标签可适度扩宽，可见边框不超过 280 CSS 像素，字号、行高和控件保持可用。
- [ ] 在两台电脑的实际缩放、宽窄列和屏幕边缘检查，确认首次居中、边缘避让及连续点击正常。
- [ ] 搜索焦点、外部点击、关闭、多选、批量选择与清除、撤销正常；非 `#` 标签保留，状态和简记无回归，后台行重绘不使菜单意外消失。
- [ ] 分别记录两台电脑在运行中升级后、重启后的结果及同一候选校验和；截图和记录不得包含用户名、本机路径、密钥或凭证。
