# Focus Columns 1.1.0 人工验收清单

本清单用于验证 `v1.1.0` GitHub Draft Release 中的确切 XPI。目前尚未完成真实 Zotero 10 人工验收，也未正式发布。自动验证通过不代表以下界面、编辑和跨电脑检查已经通过。

开始前备份两台电脑的 Zotero 数据，使用可恢复的测试条目。验收记录只保留版本、校验和、Zotero 版本、显示缩放和结果；截图与日志不得包含用户名、本机路径、密钥或凭证。

## Draft 产物准备

- [ ] 从 `v1.1.0` Draft Release 下载 `zotero-focus-columns-1.1.0.xpi` 和 `SHA256SUMS`。
- [ ] 核对下载文件的 SHA-256、`SHA256SUMS` 和 GitHub Release 资产摘要一致，并记录校验和。
- [ ] 确认 `updates.json` 仍只包含正式版本，没有 `1.1.0`。
- [ ] 两台电脑均安装同一个 Draft XPI，不以本地重建包代替。
- [ ] 从正式版升级后重启 Zotero `10.0.*`，确认插件版本为 `1.1.0`、设置页正常，原有设置和数据保留。

## 弹窗位置与交互

- [ ] 将状态列分别调整为很宽和很窄，重复点击有状态及空状态的单元格；从弹窗首次可见时观察，确认没有先靠左再跳到中央的过程。
- [ ] 在窗口及屏幕左、右、下边缘打开弹窗，确认内容可见，边缘避让不会造成再次跳动。
- [ ] 在两台电脑的实际显示缩放下重复上述检查；如使用多显示器，也在不同缩放的屏幕上检查。
- [ ] 对 `#标签` 弹窗重复宽窄列、首次定位和边缘检查。
- [ ] 对简记弹窗重复定位检查，确认输入、保存、取消和关闭正常，未因共用定位变化出现偏移或闪跳。

## #标签候选与搜索

- [ ] 在测试库准备有色、无色、中文、长名称和以 `##` 开头的原生标签；弹窗包含全部以 `#` 开头的候选，不包含其他标签，显示时只隐藏第一个 `#`。
- [ ] 确认候选来自当前文献库，不混入其他个人库或群组库的标签。
- [ ] 输入文字搜索、清空搜索，并检查无匹配结果的情况；结果和选项可读、可点击。
- [ ] 使用足够多的候选检查列表滚动和长名称显示；搜索框及清除操作仍可使用，弹窗不超出屏幕。
- [ ] 在没有 `#` 标签的测试库打开弹窗，确认空列表可理解且没有新建入口；关闭后不产生数据改动。
- [ ] 在 Zotero 原生面板创建一个新 `#` 标签，重新打开弹窗确认它可以被搜索选择。

## 单选、清除与数据保留

- [ ] 准备包含两个不同 `#` 标签及若干非 `#` 标签的条目。仅打开并关闭弹窗，确认全部原标签不变，列中仍显示原有多个 `#` 标签。
- [ ] 多个 `#` 标签不会被呈现为某一个标签已经单独选中；只有确切单值才显示相应选择状态。
- [ ] 选择另一个候选，确认全部旧 `#` 标签被替换为选中的一个；非 `#` 标签及其原有属性保持不变，弹窗保存后关闭。
- [ ] 撤销该选择，确认每个原 `#` 标签及非 `#` 标签恢复。
- [ ] 执行“清除 #标签”，确认所有 `#` 标签被移除、非 `#` 标签保留，保存后关闭；撤销后恢复原标签。
- [ ] 检查无 `#` 标签条目的首次选择、已有单个标签的重新选择，以及保存后重启 Zotero 的结果。

## 批量范围与权限

- [ ] 多选同库普通条目，分别准备相同、不同、多个及空的 `#` 标签；点击其中已选中的条目，确认弹窗不会将混合值伪装为统一单值。
- [ ] 选择一个候选，确认所有目标普通条目的 `#` 标签统一替换，各条目非 `#` 标签分别保留；一次撤销恢复各条目原有的不同标签。
- [ ] 对上述目标批量清除并撤销，确认所有原标签正确恢复。
- [ ] 保持一组条目被选中，点击未选中的普通条目，确认仅修改所点击的条目。
- [ ] 如选中范围含附件或笔记，确认它们不会被当作批量普通条目修改；其他文献库条目也不受影响。
- [ ] 在不可编辑的群组库中尝试选择及清除，确认没有写入或误导性的成功状态。

## 原有功能与第二台电脑

- [ ] 六个功能开关仍互相独立，设置页无重叠或异常滚动；两个条目面板信息行正常。
- [ ] 状态单选、清除、批量范围及撤销正常，互斥状态规则保持不变。
- [ ] 简记保存和撤销正常，条目 `Extra` 中其他内容保持不变。
- [ ] 期刊标签更新、删除及手动删除后不自动补全的行为正常；四列排序仍保留 Zotero 的次级和后备排序。
- [ ] 完成 Zotero 自带同步后，在第二台电脑确认 `#` 标签、状态及简记原生数据一致；重复关键的首次弹窗定位、单选、批量清除和撤销检查。
- [ ] 已启用插件同步时确认连接已有共享对象，期刊标签和设置两个通道仍各自工作，本机密钥不进入同步内容；关闭同步不删除共享对象。

## 正式发布门槛

- [ ] 记录两台电脑各项结果和候选 SHA-256；所有问题解决且人工验收确认通过后，才发布现有 Draft。
- [ ] 不重新构建或替换已验收 XPI，不覆盖旧版本或旧资产。验收失败时保持 Draft 未发布，在新版本中修复并重新验收。
- [ ] 发布后确认 `updates.json` 新增 `1.1.0`，公开下载地址、SHA-256 和兼容范围与正式 Release 的同一资产一致。
- [ ] 在安装正式版 `1.0.1` 的测试环境检查更新，确认 Zotero 能发现并安装 `1.1.0`，旧版本仍可下载。
