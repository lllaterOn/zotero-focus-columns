# Focus Columns 0.1.8 人工验收清单

这是在 Zotero 10 中由用户手动执行的简短验收流程，不需要使用 Codex 的电脑操作功能。
测试新的跨电脑同步功能前，请先备份 Zotero 数据目录。

## 第一台电脑

1. 安装 `dist/focus-columns-0.1.8.xpi`，然后打开 Focus Columns 设置界面。
2. 确认“跨电脑同步”默认关闭，“同步期刊标签”已勾选，“同步插件设置”未勾选，
   并确认本机已经填写的 EasyScholar 密钥仍然存在。
3. 开启“跨电脑同步”并点击“应用”。阅读启用前的说明和摘要，然后确认启用。
4. 确认“我的文库”中出现一个名为 `Personal Zotero Addons` 的“软件”条目，
   其下只有一个标题为 `Focus Columns` 的子笔记。该笔记中不得包含 EasyScholar 密钥。
5. 更新或删除一个条目的期刊标签，等待几秒，然后点击“立即检查同步数据”。
   确认界面显示的本地期刊记录数和 Zotero 同步记录数与实际情况大致相符。
6. 点击 Zotero 自带的“同步”按钮，并等待 Zotero 完成同步。

## 第二台电脑

1. 先让 Zotero 完成同步，确认上述“软件”条目和子笔记已经下载到本机，再安装插件。
2. 安装 `focus-columns-0.1.8.xpi`，开启“跨电脑同步”。确认插件提示找到了已有条目和笔记，
   而不是重新创建一套条目和笔记。
3. 选择采用 Zotero 中的期刊标签数据。确认期刊标签列恢复了数据；EasyScholar 密钥仍为空，
   或者只保留此前在这台电脑上单独填写的值。
4. 保持“同步插件设置”关闭，在第二台电脑修改一个功能开关。完成 Zotero 同步后，
   确认第一台电脑上对应的功能开关没有跟随变化。
5. 可选：开启“同步插件设置”。当本地设置与 Zotero 中的设置不同时，
   确认插件会询问采用哪一份完整设置，而不是静默覆盖其中一份。

## 安全性检查

- 关闭“跨电脑同步”后，“软件”条目及其子笔记必须保留，不得被删除。
- 将 `Focus Columns` 子笔记移入回收站后，同步必须暂停，并且插件不得自动创建新笔记。
- 从回收站恢复该笔记，再点击“立即检查同步数据”，插件应重新连接到同一个笔记。
- 卸载 Focus Columns 后，共用的“软件”条目及其任何子笔记都不得被删除。
