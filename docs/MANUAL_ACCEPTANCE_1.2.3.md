# Focus Columns 1.2.3 人工验收清单

本版本分别设计插件图标和工具栏图标，并修复启动时先出现“视图”文字的问题。维护阶段进行源码检查、自动化测试、SVG 渲染检查和 XPI 校验，不自行启动或操控 Zotero。使用本轮 Draft 的同一份 XPI，由用户验收；未报告的结果保持未勾选。

- [ ] 下载 `zotero-focus-columns-1.2.3.xpi`，确认 SHA-256 与 Draft 的 `SHA256SUMS` 一致；旧 Draft 和资产保留。
- [ ] 在 Zotero 运行期间安装本版，插件管理页与 Focus Columns 设置入口显示蓝底白色列布局图标，不再显示旧黑色网格图标。重开管理页和重启 Zotero 后也正常。
- [ ] 完全退出并重新启动 Zotero，视图组按钮始终为图标，不再瞬间出现“视图”文字；停用、启用插件也不出现文字或重复按钮。
- [ ] 浅色和深色主题、常用显示缩放下，工具栏的单色图标清晰，大小与相邻原生按钮协调，下拉箭头正常。悬停提示及当前视图名称、菜单勾选正常，键盘仍能进入并操作菜单。
- [ ] 切换、另存、更新和重命名视图后，按钮保持图标形式，提示反映当前视图；右键期刊更新/删除菜单的图标和功能正常。
- [ ] 使用同一个 1.2.3 XPI 复验 [1.2.2 清单](MANUAL_ACCEPTANCE_1.2.2.md) 中同步后列宽保持、数据刷新项目，及其引用的视图组、侧栏与跨电脑同步项目；旧清单的图标说明、版本号和发布步骤不适用于本轮。
- [ ] 用户确认后才正式发布这份 Draft 资产，不重建或替换已验收 XPI。正式发布前 `updates.json` 继续只包含已发布版本。
