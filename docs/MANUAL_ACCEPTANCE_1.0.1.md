# Focus Columns 1.0.1 人工验收清单

本清单用于验证 GitHub Draft Release 中的确切 XPI。自动测试不能替代真实 Zotero 10 界面和跨电脑同步验收。`1.0.1` 首先修复 `1.0.0` 因缺少 `update_url` 而被 Zotero 判定为无效的问题。

开始前请备份两台电脑的 Zotero 数据目录，并记录候选 XPI 的 SHA-256。不得在截图、日志或验收记录中复制 EasyScholar 密钥。

## 本地安装门槛

1. 构建本地 `zotero-focus-columns-1.0.1.xpi`。
2. 在 Zotero `10.0.*` 中从文件安装，确认不再出现“插件安装失败”提示。
3. 重启 Zotero，确认 Focus Columns 仍在插件列表中，版本为 `1.0.1`，设置页可以打开。
4. 本地安装门槛通过后，才提交源码、创建标签和 Draft Release。

## Draft 产物准备

1. 从 `v1.0.1` Draft Release 下载 XPI 和 `SHA256SUMS`。
2. 确认本地 SHA-256、`SHA256SUMS` 和 GitHub Release 资产摘要一致。
3. 确认 Draft 尚未出现在公开 `updates.json` 中。
4. 在两台电脑上均使用这个确切 XPI，不使用另一次本地重建包代替。

## 第一台电脑

1. 卸载旧的失败版本或候选版本，再安装 Draft XPI并重启 Zotero。
2. 确认插件名称、图标和版本 `1.0.1` 正确，设置页面没有横向滚动、文字重叠或异常缩放。
3. 分别切换四个条目列表列和两个条目面板信息行，确认六个开关互不影响。
4. 填写本机 EasyScholar 密钥并应用设置，验证期刊标签更新和删除。
5. 验证 `#` 标签、互斥状态以及 `remark:` 简记；确认条目 `Extra` 中其他内容保持不变。
6. 对主值相同的条目切换四个自定义列排序，确认后续顺序仍由 Zotero 的次级和后备排序决定。

## 创建新的同步数据

1. 确认跨电脑同步默认关闭，期刊标签通道默认选中，设置通道默认未选中。
2. 开启同步并确认创建计划。
3. 确认个人文献库中只出现一个 `Personal Zotero Addons` 软件条目及一个 `Focus Columns` 子笔记。
4. 确认子笔记不包含 EasyScholar 密钥、电脑名称、用户名、硬件信息或设备标识。
5. 修改一期刊标签，等待本机笔记更新，然后点击 Zotero 自带同步按钮并等待完成。

## 第二台电脑

1. 先让 Zotero 下载第一台电脑创建的共享条目和子笔记。
2. 安装同一个 Draft XPI并重启 Zotero。
3. 开启 Focus Columns 同步，确认连接已有条目和笔记，而不是创建第二套对象。
4. 采用 Zotero 中的期刊标签数据，确认期刊标签恢复；本机 EasyScholar 密钥仍为空或只保留这台电脑单独填写的值。
5. 保持设置同步关闭，在第二台电脑修改一个功能开关；完成 Zotero 同步后，确认第一台电脑没有跟随变化。
6. 开启设置同步，制造一次两端同时修改，确认插件要求选择完整的本机版本或 Zotero 版本，不静默合并。

## 异常与卸载

- 制造可恢复的同步错误，确认摘要和异常详情显示为错误状态。
- 将 Focus Columns 子笔记移入回收站，确认插件暂停且不自动创建替代笔记；恢复后可以重新连接。
- 关闭同步或卸载插件，确认共享条目和子笔记仍然保留。

## 正式发布与自动更新

1. 只有上述检查全部通过时，才发布现有 Draft；不得重新构建或替换 XPI。
2. 发布后确认 `updates.json` 新增 `1.0.1`，其中下载地址、SHA-256 和兼容范围均与正式 Release 一致。
3. 在安装了更早可更新版本的测试环境中检查更新，确认 Zotero 能发现并安装 `1.0.1`。
4. 验收失败时保持 Draft 未发布，在新的补丁版本中修复，不覆盖同版本资产。
