# Focus Columns 1.1.1 人工验收清单

本清单验证 `v1.1.1` Draft Release 的确切 XPI。当前尚未完成真实 Zotero 10 验收，也未正式发布。`1.1.0` 候选和原清单保留，不替换资产、不正式发布。

自动验证不能代替对用户 GIF 中弹窗消失、连续点击、焦点和多选变化的真实复验。以下项目应在两台电脑上记录结果。开始前备份数据并使用可恢复的测试条目；截图、录屏和记录不得包含用户名、本机路径、密钥或凭证。

## 候选与升级

- [ ] 从 `v1.1.1` Draft 下载 `zotero-focus-columns-1.1.1.xpi` 和 `SHA256SUMS`，核对文件 SHA-256、校验和文件及 GitHub 资产摘要一致。
- [ ] 两台电脑均使用同一个已核对的 Draft XPI，不使用另一次本地重建包代替。
- [ ] 从正式版 `1.0.1` 或旧候选升级并重启 Zotero `10.0.*`，确认版本 `1.1.1`、设置和原数据正确。
- [ ] 确认 `updates.json` 仍只含正式版本，不包含 `1.1.0` 或 `1.1.1` 候选。

## 宽度、位置与连续点击

- [ ] 使用只有短标签的库打开 `#标签` 弹窗，确认宽度约为 180–200 CSS 像素，字号、行高和搜索框未被压缩。记录显示缩放，勿将截图物理像素直接当成 CSS 像素。
- [ ] 加入长标签检查有限扩宽，目标上限为 280 CSS 像素；长名称、清除操作和搜索仍可使用，不出现失控扩宽。
- [ ] 连续打开和关闭同一单元格、切换不同条目、在 `#标签` 和状态列之间反复点击，确认菜单不会闪现后消失或需要额外点击才能正常使用。
- [ ] 将两列分别调宽、调窄，检查首次可见时已居中，没有先靠左再移动。
- [ ] 在窗口与屏幕边缘、两台电脑的实际显示缩放下重复上述操作；使用不同缩放显示器时也检查跨屏表现。

## 焦点与关闭

- [ ] 列表有焦点时打开 `#标签` 弹窗，确认搜索框没有自动取得输入焦点；观察原有蓝色选中样式，确认不因打开搜索而立即变灰。
- [ ] 点击搜索框后可正常输入和筛选；此时列表失去焦点出现灰色属于可能的原生表现，不能因此判定已丢失多选，应同时检查选中条目集合。
- [ ] 选择标签、清除或取消关闭后，在适当情况下列表恢复焦点，键盘导航和撤销可用；重复检查蓝灰样式与实际焦点一致。
- [ ] 搜索期间点击 Zotero 的其他输入框或控件关闭弹窗，确认焦点留在所点击的位置，不被延迟抢回列表。
- [ ] 点击弹窗外、按 Escape 关闭以及再次打开，确认搜索输入和关闭行为正常，不发生额外编辑。

## 多选与撤销

- [ ] 多选同库普通条目，按下再松开已选中行的 `#标签` 单元格，确认选中集合没有收缩为一行；对状态列重复检查。
- [ ] 对保留的多选执行标签选择和清除，确认全部目标被修改，非 `#` 标签保持不变；一次撤销恢复每个条目原有的不同标签。
- [ ] 对状态列执行批量选择、清除和撤销，确认目标范围及互斥状态规则保持正确。
- [ ] 多选后点击未选中的普通条目，确认编辑仅作用于点击的条目；附件、笔记及其他库条目不进入普通条目批量范围。
- [ ] 在不可编辑库中尝试操作，确认不发生写入或误导性的成功状态。

## 列表重绘与位置失效

- [ ] 打开菜单后触发正常的后台数据刷新，让条目行发生重绘；菜单保持可用，不因原行被替换而突然隐藏。
- [ ] 在上述情况下执行一次选择并撤销，确认仍编辑打开时确定的正确目标，不错用后来重绘的行。
- [ ] 打开菜单后移动或调整窗口、滚动条目列表，确认菜单在原位置不再适用时合理关闭，不悬留在错误位置。
- [ ] 滚动弹窗内部的长候选列表时，确认菜单不会被误判为条目列表滚动而关闭；搜索后仍可正常选择。

## 功能回归与两台电脑

- [ ] 候选仍来自当前库全部原生 `#` 标签，包括无色标签；显示只去掉首个 `#`，没有新建入口。搜索、多候选滚动、无匹配和空列表正常。
- [ ] 打开或取消弹窗不修改原有多个 `#` 标签；混合或多个值不伪装为单一选中。主动选择或清除才替换或移除全部 `#` 标签，保留其他标签并支持撤销。
- [ ] 简记共用定位回归通过：宽窄列、屏幕边缘、连续打开、输入、保存、取消、撤销与关闭均正常，`Extra` 其他内容保留。
- [ ] 六个独立开关、两条信息行、期刊标签更新和删除、四列次级排序保持正常。
- [ ] 完成 Zotero 同步后，在第二台电脑确认标签、状态和简记一致；重复连续点击、焦点、多选及后台刷新检查，并记录该电脑的缩放与结果。
- [ ] 已启用插件同步时仍连接原共享对象，期刊与设置通道各自正常，密钥不进入同步内容，关闭同步不删除共享对象。

## 发布门槛

- [ ] 汇总两台电脑结果和同一候选的 SHA-256；对 GIF 中的现象完成真实复验，用户确认通过后才正式发布现有 `1.1.1` Draft。
- [ ] 不重建或替换已验收 XPI，不发布旧 `1.1.0` Draft，不覆盖旧版本资产。失败时保持候选未发布，使用新版本修复并重新验收。
- [ ] 发布后确认 `updates.json` 新增 `1.1.1`，公开地址、SHA-256 及兼容范围对应已验收的正式资产；`1.1.0` 仍不进入更新清单。
- [ ] 从正式版 `1.0.1` 检查自动更新，确认可发现并安装 `1.1.1`，旧正式版仍可下载。
