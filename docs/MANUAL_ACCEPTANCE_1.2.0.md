# Focus Columns 1.2.0 人工验收清单

当前为待验收候选，尚未正式发布。维护阶段只运行项目检查并交付 Draft XPI，不启动或操控 Zotero 测试。以下项目由用户使用同一个 `1.2.0` Draft XPI 在真实 Zotero 中检查；自动测试不能替代人工结果。尚未报告的项目保持未勾选。

## 确切候选与升级

- [ ] 从 `v1.2.0` Draft 下载 `zotero-focus-columns-1.2.0.xpi` 和 `SHA256SUMS`，确认下载文件的 SHA-256、校验和文件及 GitHub 资产摘要一致；两台电脑均使用这个确切 XPI。
- [ ] 从正式版 `1.1.3` 在 Zotero 运行中升级，再重启复验。确认工具栏只有一个视图组菜单，原六个功能开关、设置、标签、简记和期刊缓存保留；禁用插件移除菜单，再启用正常恢复。
- [ ] 记录两台电脑的 Zotero 版本、显示缩放、候选校验和与结果；记录和截图不含用户名、本机路径、密钥或凭证。

## 保存与切换

- [ ] 在工具栏将两种不同的列显隐、顺序和宽度另存为不同名称的组；切换后布局正确。重命名、组上移与下移、删除及取消操作正常；空名称、重复名称有明确提示。
- [ ] 修改列布局后，切走再切回不会自动覆盖已保存组；主动“更新当前视图”后，再次切换和重启仍能恢复所保存布局。反复切换不会使列宽因边距不断漂移。
- [ ] 设置主排序和次级排序，包含同主排序值的多条记录；切换到隐藏主排序列的组后，排序方向及实际条目次序保持。搜索词、标签筛选、当前分类、单选和多选均保持。
- [ ] 在不同文献库、分类及窄窗口中检查菜单和布局；特殊视图不支持时明确禁用相关操作，不破坏布局或条目选择。当前组是本机状态，不为每个文献库独立保存。
- [ ] 临时禁用提供某列的插件后切换并更新组，再恢复该插件并重新切换；该列原有显隐与顺序定义仍保留。原生必须保留的主列正常可用。

## 两台电脑与同步兼容

- [ ] 两台电脑均安装 `1.2.0`，启用设置同步并完成 Zotero 原生同步。新增、重命名、组排列和列显隐顺序能传到另一台电脑；不依赖手工修改同步笔记。
- [ ] 两台电脑给同一个组分别调整并更新不同列宽，来回同步和切换后保留各自宽度；当前组选择不跟随另一台电脑改变。首次在本机使用尚无保存宽度的组，列宽沿用本机可用值。
- [ ] 尚未使用视图组时，升级和同步保留旧设置格式；关闭设置同步、仅在本机保存组时，不改变共享笔记格式。期刊标签同步仍可独立使用。
- [ ] 在隔离测试环境检查新格式提示：首次将组同步到共享笔记后，旧版客户端明确提示更新并暂停 Focus Columns 同步，不改写新数据；升级至 `1.2.0` 后可继续。不要为此降级日常使用的电脑。
- [ ] 两端分别修改组或其他同步设置时，出现完整设置版本的冲突选择；明确选择后结果符合选择，未静默合并。读取不含组的旧设置或恢复旧备份，不删除已有本机组；新格式的明确空组列表可删除共享组定义。
- [ ] 恢复设置备份和处理冲突后，本机各组列宽、当前组状态及 EasyScholar 密钥未被远端值替换。同步开关、密钥和本机连接信息没有进入同步笔记。

## 原有功能与发布

- [ ] 使用本轮同一个 `1.2.0` XPI 复验 [1.1.3 清单](MANUAL_ACCEPTANCE_1.1.3.md) 的运行中样式升级、弹窗宽度及功能回归部分，并沿用其引用的回归项目；旧清单的版本号和发布步骤不适用于本轮。
- [ ] 期刊标签、`#标签` 单选及清除、状态、简记、撤销、多选范围和条目面板功能正常；两台电脑设置页同步说明显示完整。
- [ ] 用户确认验收通过后，才正式发布现有 `1.2.0` Draft；不得重建或替换已验收 XPI。失败时使用新版本修复，保留本候选与资产。
- [ ] 发布前 `updates.json` 仍仅包含正式版本；发布后核对新增 `1.2.0` 的公开地址、SHA-256 和兼容范围与已验收资产一致，并检查原生自动更新。历史版本及未发布候选保持不变。
