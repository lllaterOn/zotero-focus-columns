# Focus Columns 1.2.2 人工验收清单

本版本修复同步通知后不必要的列布局重建，并重绘插件及工具栏共用图标。基础代码检查、自动化测试和包校验由维护阶段完成；不自行启动 Zotero，实际交互由用户测试。使用本轮 Draft 的同一份 XPI，未报告的结果保持未勾选。

- [ ] 下载 `zotero-focus-columns-1.2.2.xpi`，确认 SHA-256 与 Draft 的 `SHA256SUMS` 一致；旧 Draft 及其资产保留。
- [ ] 从 1.2.1 升级后，在列表宽度和侧栏状态不变的情况下，选择视图、微调列宽、不更新视图，然后执行一次及连续多次 Zotero 同步；当前列边界保持，数据正常更新。
- [ ] 重复上述过程，但在微调后先“更新当前视图”，再同步；列宽同样保持。切换到其他视图再回来，可恢复手动保存的布局。
- [ ] 列表当前有单选、多选或搜索时重复同步；条目数据更新正常，插件刷新不重设布局或选择。期刊标签、#标签、状态、简记及其清除、撤销功能正常。
- [ ] 接收另一台电脑更新的期刊数据和显示设置后，列表及信息行及时更新，普通数据刷新不重建列宽。同步中明确改变列功能开关时，列增减仍正常生效。
- [ ] 插件管理页、设置入口、右键菜单和工具栏使用新图标；在深浅主题及常用缩放下线条清晰，与原生按钮协调。工具栏的下拉箭头、提示和当前视图标记正常。
- [ ] 使用同一个 1.2.2 XPI 复验 [1.2.1 清单](MANUAL_ACCEPTANCE_1.2.1.md) 中工具栏和侧栏项目，以及其引用的视图组与跨电脑同步项目；旧清单版本号与发布步骤不适用于本轮。
- [ ] 用户确认后，才正式发布这份 Draft 资产；不重建或替换已验收 XPI。正式发布前 `updates.json` 继续只包含已发布版本。
